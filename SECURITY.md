# Política de Segurança

Este repositório é um material de documentação (guias em Markdown e templates
do GitHub) — não há código executável em produção nem dados de usuários
envolvidos. Ainda assim, mantemos uma política de divulgação responsável para
os cenários que se aplicam a este tipo de projeto.

## O que é considerado um problema de segurança aqui

- Links em `docs/` ou no `README.md` apontando para conteúdo malicioso ou
  comprometido.
- Comandos de exemplo (ex.: nos guias de instalação) que induzam o leitor a
  executar algo perigoso.
- Vulnerabilidades nas *GitHub Actions* de terceiros usadas em
  `.github/workflows/`.

Erros de digitação, conteúdo desatualizado ou sugestões de melhoria **não**
são problemas de segurança — abra uma Issue normal usando o template de
[Sugestão de Melhoria](.github/ISSUE_TEMPLATE/feature_request.md) para esses
casos.

## Como reportar

Envie um e-mail para **engenharia.al2tecnologia@gmail.com** com:

1. Uma descrição clara do problema encontrado;
2. O arquivo ou link afetado;
3. Se possível, uma sugestão de correção.

Você receberá uma resposta em até 5 dias úteis. Evite abrir uma Issue pública
para vulnerabilidades ainda não corrigidas nas Actions de terceiros, para dar
tempo de mitigação antes da divulgação.
